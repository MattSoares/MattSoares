## Projetos em destaque

### 🦷 Clínica OdontoVida

Sistema full stack para gestão de uma clínica odontológica fictícia, desenvolvido como projeto de estudo e portfólio.

- Autenticação com JWT e controle de acesso por perfil
- Gerenciamento de pacientes, profissionais e usuários
- Agenda com criação, edição e cancelamento de consultas
- Validação de disponibilidade e conflitos de horário
- Histórico de consultas e dashboard administrativo
- Integração entre frontend, API REST e MongoDB

**Tecnologias:** React, Vite, styled-components, Axios, Node.js, Express, MongoDB, Mongoose e JWT.

[![Ver repositório](https://img.shields.io/badge/Ver_repositório-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/MattSoares/clinica-odontovida-api)

### 🔥 FireWatch

Sistema de detecção de risco de incêndios desenvolvido para a **FIAP Global Solution 2026**. O protótipo utiliza sensores para monitorar temperatura, umidade e fumaça, classificando o risco em diferentes níveis.

**Tecnologias:** Arduino, C++, DHT22, MQ-2, LCD I2C, ArduinoJson, Wokwi, HTML, CSS e JavaScript.

[![Ver repositório](https://img.shields.io/badge/Ver_repositório-181717?style=for-the-badge&logo=github&logoColor=white)](https://lnkd.in/dUWpz2TQ)
